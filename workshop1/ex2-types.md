ชนิดของข้อมูลใน JavaScript โดยสร้างตัวแปรขึ้นมาหลายแบบเพื่อดูว่าแต่ละตัวมีชนิดข้อมูลอะไร เช่น ข้อความจะเป็น string ตัวเลขจะเป็น number และค่าจริงหรือเท็จจะเป็น boolean ส่วน undefined คือการประกาศตัวแปรไว้แต่ยังไม่ได้ใส่ค่า และ null คือการกำหนดให้ตัวแปรไม่มีค่า

จากนั้นใช้ typeof เพื่อตรวจสอบชนิดข้อมูลของตัวแปรแต่ละตัว ซึ่งมีจุดที่น่าสนใจคือ typeof null จะได้เป็น object ถึงแม้ว่า null จะไม่ได้เป็น object จริง ๆ ส่วน NaN ก็ยังมีชนิดข้อมูลเป็น number

ในส่วนของอายุ ตอนแรก inputAge เป็น "20" ซึ่งเป็นข้อความ ไม่ใช่ตัวเลข ผมเลยใช้ Number(inputAge) เพื่อแปลงเป็นตัวเลขก่อน ถึงจะสามารถเอาไปคำนวณต่อได้
