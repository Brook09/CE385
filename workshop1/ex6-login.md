ข้อนี้เป็นระบบตรวจสอบการเข้าสู่ระบบ โดยจะตรวจสอบข้อมูลตามลำดับ เพื่อให้ระบบทำงานถูกต้องและไม่ตรวจสิ่งอื่นก่อนที่จะยืนยันตัวตน

อย่างแรกคือเช็ก username และ password ก่อน ถ้าผิดก็จะ return ข้อความว่าชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง และให้รหัส 401

ถ้ารหัสผ่านถูก ก็จะตรวจต่อว่าบัญชีถูกระงับหรือไม่ ถ้า isActive เป็น false ก็จะแจ้งว่าบัญชีถูกระงับและให้ 403 หลังจากนั้นจึงตรวจอายุว่าถึง 18 ปีหรือยัง แล้วค่อยตรวจ role ว่าเป็นอาจารย์หรือนักศึกษา

ใช้ return ในฟังก์ชัน เพราะต้องการให้ฟังก์ชันส่งผลลัพธ์กลับมา แล้วค่อยนำผลลัพธ์นั้นไปแสดงด้านนอกฟังก์ชัน ทำให้ฟังก์ชันไม่ได้มีหน้าที่แสดงผลเอง
