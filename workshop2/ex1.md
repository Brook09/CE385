# Workshop 2
## ข้อ 1 ฟังก์ชันคำนวณคะแนน
ไฟล์ `ex1-functions.js`

ข้อ 1 เป็นการสร้างฟังก์ชันสำหรับตรวจสอบคะแนน แปลงคะแนนเป็นเกรด และคำนวณคะแนนรวม
```javascript
isValidScore()
ใช้ตรวจสอบว่าคะแนนอยู่ในช่วง 0–100 หรือไม่

score >= 0 && score <= 100

ถ้าอยู่ในช่วงที่กำหนดจะคืนค่า true และถ้าอยู่นอกช่วงจะคืนค่า false

===============================================================================
toGrade()
ใช้แปลงคะแนนเป็นเกรด โดยตรวจสอบคะแนนตามช่วงจากคะแนนสูงไปต่ำ เช่น
- 80 ขึ้นไป = A
- 75 ขึ้นไป = B+
- 70 ขึ้นไป = B
- 65 ขึ้นไป = C+
- 60 ขึ้นไป = C
- 55 ขึ้นไป = D+
- 50 ขึ้นไป = D
- ต่ำกว่า 50 = F
==============================================================================
calculateWorkshopScore()
ใช้คำนวณคะแนน Workshop จากคะแนนที่ทำได้ โดยมีสูตร

(raw / full) × weight

โดยกำหนดค่าเริ่มต้นเป็น
full = 60
weight = 20

ตัวอย่าง (48 / 60) × 20 = 16
==============================================================================
calculateTotal()
ใช้รวมคะแนนของนักศึกษา 5 ส่วน ได้แก่ Workshop, Attendance, Project, Midterm และ Final

มีการสร้างข้อมูลนักศึกษา 3 คนเพื่อทดสอบการทำงานของฟังก์ชัน และแสดงคะแนนรวมกับเกรดของแต่ละคน
