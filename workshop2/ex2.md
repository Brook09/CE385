==============================================================================
```javascript
findById()
ใช้ find() เพื่อค้นหานักศึกษาจาก ID

students.find((student) => student.id === id)

find() จะคืนข้อมูลนักศึกษาคนแรกที่ตรงกับเงื่อนไข หากไม่พบข้อมูลจะคืน undefined
===============================================================================
findByMajor()
ใช้ filter() เพื่อเลือกนักศึกษาที่อยู่ในสาขาที่กำหนด

students.filter((student) => student.major === major)

เนื่องจากอาจมีนักศึกษาหลายคนในสาขาเดียวกัน จึงได้ผลลัพธ์เป็น Array
===============================================================================
hasFailingStudent()
ใช้ some() เพื่อตรวจสอบว่ามีนักศึกษาที่คะแนนต่ำกว่า 50 หรือไม่

ถ้ามีนักศึกษาอย่างน้อย 1 คนที่คะแนนต่ำกว่า 50 จะคืนค่า true
===============================================================================
getEmail()
ใช้ค้นหา Email ของนักศึกษาจาก ID

มีการใช้ Optional Chaining ?. เพื่อป้องกัน Error ในกรณีที่ไม่พบข้อมูล และใช้ Nullish Coalescing ?? เพื่อกำหนดข้อความสำรองเมื่อไม่มี Email
