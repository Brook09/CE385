### ข้อ 3 เป็นการประมวลผลข้อมูลนักศึกษาโดยใช้ Array Methods ได้แก่ map(), filter() และ reduce() และไม่มีการใช้ for หรือ while
===============================================================================
```javascript
getNames()
ใช้ map() เพื่อสร้าง Array ใหม่ที่เก็บเฉพาะชื่อของนักศึกษา

students.map((student) => student.name)
===============================================================================
getPassedStudents()
ใช้ filter() เพื่อเลือกนักศึกษาที่มีคะแนนตั้งแต่ 50 คะแนนขึ้นไป

students.filter((student) => student.score >= 50)
===============================================================================
getTotalScore()
ใช้ reduce() เพื่อรวมคะแนนของนักศึกษาทั้งหมด

students.reduce(
  (total, student) => total + student.score,
  0
)
ค่า 0 เป็นค่าเริ่มต้นของตัวแปรที่ใช้สะสมผลรวม
===============================================================================
getAverageScore()
ใช้คะแนนรวมมาหารด้วยจำนวนนักศึกษาเพื่อหาคะแนนเฉลี่ย

ถ้า Array ไม่มีข้อมูล จะคืนค่า 0 เพื่อป้องกันการหารด้วยศูนย์
===============================================================================
countByGrade()
ใช้ reduce() ในการนับจำนวนนักศึกษาแต่ละเกรด โดยตรวจสอบคะแนนของแต่ละคนแล้วเพิ่มจำนวนของเกรดนั้น
ตัวอย่างผลลัพธ์
{
  A: 2,
  B: 1,
  C+: 1,
  D+: 1,
  F: 1
}
===============================================================================
getTopStudent()
ใช้ reduce()เพื่อเปรียบเทียบคะแนนของนักศึกษาแต่ละคนและคืนข้อมูลของนักศึกษาที่มีคะแนนสูงสุด
หากไม่มีข้อมูลนักศึกษา จะคืนค่า undefined

การใช้ filter → map → reduce
มีการประมวลผลข้อมูลแบบต่อเนื่อง
students
  .filter(...)
  .map(...)
  .reduce(...)

โดย filter() ใช้คัดเลือกข้อมูล map() ใช้เลือกหรือเปลี่ยนข้อมูล และ reduce() ใช้รวมข้อมูล
